# 書類取込の実モデル評価（2026-11-20、Issue #18）

結論：独立した選択欄照合を追加し、既知の薄い印・複数印・無印を保留できた。通常版とスキャン版の55項目、大阪市版の対象3項目も一致した。ただし各ケース1回の架空資料での結果であり、未知の実書類で同じ精度を保証しない。確認時間などの未検証条件が残るためPR #139はDraftを維持する。

## 評価条件

- `gemini-3.8-flash`、Vertex AI `global`。実利用者データは使用していない。
- 読取→共通Visit→共通の要約・欄選択・書き込み・最終チェックを、通常の非公開原本保存とジョブで実行。値は候補のままで、自動採用しない。
- 通常・難読・無印・スキャンは同じ広島市版に架空の回答を記入した関連サンプル。55項目を評価する。難読では2-2と2-4、無印では2-5の候補を出さず、その項目に結びつく要確認記録がある場合だけ「安全な保留」と数える。
- 大阪市版は[公開様式](https://www.city.osaka.lg.jp/fukushi/cmsfiles/contents/0000674/674268/9.pdf)の画像形式の基本調査ページに3項目を記入したもの。PNG・JPEGは項目名を明記した別書式の合成別紙。いずれも対象3項目だけを採点し、用紙全体の精度とは扱わない。
- writerの並列数は4。処理時間はジョブ実行から候補生成までで、ファイル選択・アップロード・ケアマネの確認時間を含まない。以前の並列数1の評価との速度差を、今回の読取対策だけの効果とは扱わない。
- 費用は既存Gemini基盤が応答の利用量から計算した円換算見込額。中断・時間切れで応答を得られなかった呼出の課金は不明で、記録した見込額が請求の上限という意味ではない。
- 根拠追跡は「候補のIDが判読確実な原文に到達する割合」。意味の裏付けや、人が原本を開いて照合できた割合とは区別する。

## 最新main統合後の確認

main `be84611` のAI点検機能を取り込み、キュー・worker・ペット画面の両機能を維持して競合を解消した。main側で共通の欄選択プロンプトも変更されていたため、統合版 `a43faec` で難読PDFを1件だけ追加評価した。

結果は53項目一致、薄い印・複数印の2項目を安全に保留、誤候補・欠落0件。根拠IDは65/65件を追跡可能。353.2秒、42呼出、見込34.99円（上限45円以内）。各1回の評価であり、統合後に7件すべてを再実行した結果ではない。上記2回の見込203.27円と合わせると、この3回の全経路評価の応答済み利用量は見込238.26円。予備試行および応答を得られなかった呼出の費用は含めない。

## 実装した対策

1. 原本の選択欄を、項目見出し・回答方法・全選択肢の文字と印の状態として読む。サーバーでも薄い印、無印、単一選択欄の複数印、回答方法不明を保留する。明記された複数回答可の複数印は許容する。
2. 原本画像に加え、薄い画素を除いた補助画像から印だけを独立に読む。照合側には項目名と全選択肢だけを渡し、原本で読んだ選択状態を教えない。不一致、照合不能、返答の欠落・重複があれば保留する。補助画像で消えた薄い印を「未選択の確定値」としては扱わない。
3. 不確実な項目と同じ版の辞書の見出しは、別の明瞭な特記事項で補って候補にしない。writerが返した候補もサーバー側で除外する。書類専用の座標やフィールド対応表は本体に追加しない。
4. 照合結果もページキャッシュに保存し、再試行で判定を失わない。警告が100件を超えても全行の不確実フラグを保持する。
5. PDF.jsに同梱WASMの場所を渡し、圧縮画像を欠落させずに描画する。復号に失敗した画像XObjectは白紙の正常な原本として処理を続けない。
6. Geminiの1試行は認証待ちを含め120秒で中断し、既存の回数上限付きリトライを使う。中断がサービス側の処理・課金の取消を保証するものではない。

## 評価で見つかった失敗と修正

- 初回評価では、通常・スキャンが54/55、難読が52/55で、薄い印・複数印を保留できなかった。原本の単純な再照合や濃淡の強調だけでは改善を確認できず、採用しなかった。
- 大阪市版の最初の評価は0/3。モデルへ渡す画像から用紙本体が欠落し、追記した印と文字だけになっていた。WASM設定を補って原本の描画を確認し、同じ入力ファイルで再評価した。
- スキャンの最初の再評価は通信が長時間停止し、リース期限後の状態がprocessingのまま終了したため不合格として記録した。認証先DNSのエラーも記録された。120秒の待ち時間上限を追加し、スキャン・大阪市版・PNG・JPEGだけを再実行した。
