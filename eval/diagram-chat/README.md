# 図チャットの実モデル検証

`run.ts` は架空の家族・身体症状だけを送る。`npm test` では実行しない。

```sh
GOOGLE_CLOUD_PROJECT=<検証用プロジェクト> node eval/diagram-chat/run.ts
```

6ケース: 記録から家族図／対象人物の訂正／本人基準の左右としびれ／不明部位／矛盾時の質問／他症状を保持した部位訂正。図を選んで開いた画面と同じ `diagramField` 付きの経路を使う。対象図・根拠の先読み、指定外の変更拒否、相談全体の期限も適用される。

`DIAGRAM_CASE` で1ケースを指定、`DIAGRAM_EVAL_OUTPUT` で結果を保存できる。認証は既存のVertex AI設定を使う。実モデルの費用が発生する。通信・モデルの変動によって失敗することも成功率の評価に含め、成功した実行だけを品質保証として扱わない。

`DIAGRAM_EVAL_ARTIFACT_DIR` を指定すると、チェックに通った構造化データから、既存の描画コードでSVG・PNGを作り、返答JSONとともに保存する。図の版番号も検査する。AIに画像や描画コードを書かせる検証ではない。存在しないケース名はエラーにし、0件の検証を成功扱いしない。
