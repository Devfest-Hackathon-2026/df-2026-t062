# ケアプラン UI（#90・PR4）

## 既存画面との関係

- PC の作業画面に「ケアプラン」の入口を置く。iPad では既存の書類メニューから開く。
- PCでは既存 `PcWork` のヘッダー・書類タブ・3列レイアウトを維持し、左と中央をケアプランに切り替える。右の `PetHelper` は同一インスタンスを保ち、開いたメニューや相談履歴を切り替えだけでは失わない。
- 右パネルの確認・取り込み・相談は、従来の参照元書類を対象に保持し、その入力先を明示する（ケアプランへの自動同期や反映ではない）。確認欄から参照元に戻るときは未保存の破棄を確認する。ケアプラン本文を直接相談・適用する機能は別途未完了。
- アセスメントとケアプランは `SheetToolbar` を共用し、用紙見出し・凡例・拡大縮小・保存の配置とスタイルを統一する。左ナビ、中央の枠・背景・スクロールも既存の作業画面に合わせる。
- PC上部の状況表示と「書類を出力」はアセスメントと `DocumentOutput` を共用する。ケアプランには必須欄の定義がないため、入力率を作らず第1〜3表の保存状態を表示する。未保存・読み込み中・処理中は出力できない。
- 計画版の選択・作成・AI原案・確定などの操作は左ナビの表選択より下にまとめ、用紙上部をアセスメントと同じ高さから開始する。未保存の案内やエラーは用紙内に表示する。
- 「ケアプランを作成」の入口は書類タブの外、PCヘッダー右上に独立して配置する。iPadの書類メニューでは独立したケアプランの区画に配置する。薄紫の枠・背景とアイコンでも補助する。
- 第1〜3表を個別に汎用の「書類を作る」で作らず、1つの計画版として作る。
- アセスメント・入院時情報提供書・録音・ペットの確認/相談/取り込みの既存経路は残す。iPad は録音中・送信中にはケアプランへ切り替えない。
- 色・ボタン・用紙中心の第1表は既存UIに合わせる。横A4は様式の寸法で座標・文字サイズ・画像比率を計算し、既存の縦A4もそのまま扱う。

## 保存（ユーザー確認済み）

各表の上下に「保存」を置き、隣に **「第1〜3表の変更をまとめて保存します」** と明記する。

1. 全3表の書類に対する入力送信を待つ。
2. 第2表の変更があれば、stable ID を保って更新する。
3. 第3表の変更があれば、更新後の `baseVersion` で更新する。
4. 3表の保存版をまとめて作る。
5. 保存済みの値を読み直してから「第1〜3表を保存しました」と表示する。

- 入力の自動送信と、保存版の作成は別。送信キューが空になっても現在値と保存値が違えば未保存と表示する。
- API の `hasUnsavedChanges` は、構造と全3表の独立した入力欄を保存版と比較する。画面を開き直したときも未保存を見失わない。
- 途中で失敗しても成功表示しない。すでに更新できた構造の `lockVersion` は保持して、古い版番号で再試行しない。
- 競合時に利用者の入力を自動で捨てない。「読み直す」前に破棄を確認する。未保存の移動・ページを閉じる操作にも確認を出す。
- ケアプランでは文単位の保存ボタンは出さない。既存アセスメントのページ・文単位保存は変更しない。
- **保存によって確定しない。**

## 編集

- 第1表：既存の用紙上の入力・丸印・差分表示を使用する。
- 第2表：厚生労働省の公式原紙画像を表示し、公式の欄を押してニーズ・長期目標・短期目標・サービスを入力する。独自の表は生成しない。追加・削除・並べ替えは入力補助ダイアログで行い、サービスを削除すると対応するローカルの週間予定も外す。
- 第3表：厚生労働省の公式週間サービス計画表の原紙画像を表示する。独自の週間グリッドや罫線は生成しない。公式の週間枠・日常生活活動・週単位以外の欄に入力値を重ね、押すと入力補助ダイアログを開く。入力途中の予定は「予定を追加・編集」から再開できる。
- 第2・3表はPDFと共通の `core/print-layout.ts` で公式様式の欄座標に値を配置する。続きも同じ公式原紙を使う。画面での長文入力は保持し、PDFのoverflow検証は従来どおり省略せず行う。
- 第2/3表の氏名・作成日は各公式原紙上の欄で編集する。第1表を直しても自動同期しない。
- 新しいサービスは第2表を保存してIDを確定させてから、週間予定に割り当てる。
- ダイアログの「閉じる」は入力を画面内に保持するだけで、保存完了の意味にはしない。

## AI・確定・PDF

- AI は任意。保存済みアセスメントの版番号と保存日時を選び、原案を見てから明示的に適用する。
- 参照版が固定されること、人の値を上書きしないこと、適用と保存・確定が別であることを表示する。
- 「前回のAI原案を開く」で、保存された最新原案を再生成せず再開できる。原案の取得も計画・事業所で絞る。
- 失敗しても手入力を妨げない。部分適用・適用なしを全件成功と表示しない。
- 確定は未保存がないときだけ別の確認ダイアログを開く。確定後は全表を閲覧専用にし、訂正は改定版を作る。
- PDF は保存した3表の一括出力。未保存があれば保存を案内し、422 overflow は該当の印字欄名を表示する。
