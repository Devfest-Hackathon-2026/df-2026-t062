# ケアプラン関係書類の入口の集約

2026-11-23。PR #197 の第4〜7表復活を前提とする、別PRの変更。

- PCの書類タブとiPadの書類メニューに「ケアプラン」を置き、その中で第1〜3表・第4表・第5表・第6表・第7表を切り替える。
- サービス利用票・利用票別表などの入口を、一般書類タブと「書類を作る」から外す。表示可能な書類種別と既存書類を参照する。
