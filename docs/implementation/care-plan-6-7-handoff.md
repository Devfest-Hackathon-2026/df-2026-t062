# 第6・7表の引き継ぎ

## 現在地

- 土台は [PR #197](https://github.com/cloud0327/df-2026-t062-dev/pull/197) の先頭コミット `69eddf0`。第6表は、確定した第3表の週次予定から対象月の利用日を作成し、予定と実績を分けて保存する。第7表は、第6表の特定の保存版と算定条件を参照し、算定結果を版付きで保存する。
- PR #197 では、第6・7表を公式原紙と印字座標で表示する。今回作った [操作デモ](prototypes/care-plan-fee-paper.html) は、原紙を主画面に置いた場合のUIを共有するための別ファイル。PR #197 の欄を参考にした架空データの用紙で、ブラウザーでローカルに開ける。
- Excelを使った裏側の転記・再計算、AIによるExcel操作、算定結果の照合、第6表の選択中の保存版を第7表へ引き継ぐ操作は実装前。このPRの差分は引き継ぎ資料とUI見本。

## UIと業務上の前提

- 第6・7表の主画面は用紙。算定済みの値は用紙の該当欄に入れる。人の確認が必要な場合は、該当欄と確認する内容を表示する。検算表や数式は、利用者の画面には出さない。
- Excelは裏側で、AIが照合・入力するデータを受け取り、管理された数式で計算する。AIが拾った情報は参照元とともに残す。サービスコード、地域区分、負担割合、算定条件の不足は要確認にする。
- 第7表からでも閲覧・レビューを始められる。対象月、第6表の保存版、予定・実績の区分を画面で確認できるようにする。参照元が更新された場合は古い算定を区別し、新しい版で再計算してから今回の算定を確定する。過去の確定結果は履歴から参照できるようにする。
- 今回の対象は第6・7表。第2表のセル編集の試作は作業対象から外した。

## 次に実装すること

1. 第6表の保存版を第7表へ渡し、対象月と版番号を引き継ぐ。既存の画面から直接第7表を開いても保存版を選べるようにする。参照元の変更と再計算を分けて扱う。
2. 第6表の保存版、算定条件、承認済みの算定マスターをExcelの管理テンプレートへ転記する。テンプレートの版、入力、結果の対応を記録する。実績未入力などの判定は金額を保留する条件として扱う。
3. 現行の算定処理とExcelの結果を照合する。公的資料から独立して求めた期待値も使い、予定と実績の差、取消、実績未入力、端数の切り捨て、マスター適用月の境界を確かめる。照合結果を確認できた値を第7表の欄へ反映する。

## 確認状況

- 操作デモをオフラインのChromiumで確認済み。入力済みの用紙、実績未入力による保留、該当欄からの確認、用紙の拡大、狭い画面での表示を試した。
- デモの「確認済みにする」は表示状態の切り替え。デモはExcel、AI、API、DBを呼び出さず、算定の確定・保存を行わない。
- PR #197 の現行マスターの検証範囲は、2026年6〜11月の身体介護1。単一サービス・単一事業所・1日1回まで・限度内などの条件を満たす場合に限定される。条件が足りない場合は「未計算・要確認」とする。根拠と既存の検算例は [サービス利用票別表の算定仕様](../サービス利用票別表_算定仕様.md) と `test/fixtures/care-fees/expected.json` を参照。
