## 採用された仕様

1. 「ケアプラン」を開くと左に第1〜7表を縦に並べる。
2. 中央は第1〜7表を順番につなげ、スクロールだけでも全表・全ページを閲覧できる。
3. 左一覧のクリックは中央だけを該当用紙へ移動。スクロール時も選択表示を同期する。
4. 保存済み書類は自動表示。未作成なら空の公開様式を表示し、閲覧のために記録を作らない。
5. 入力・保存・確定・履歴・算定の既存状態を維持。左一覧・右ペットパネル・画面全体を一緒にスクロールさせない。
