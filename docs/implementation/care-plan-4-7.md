## 第6表・月間展開の基盤（#94 中間）

- core/care-month.ts は確定スナップショットschemaVersion=1とconfirmation IDを入力に、stable serviceId/slotIdを含む日別予定を決定的に展開する。ホストTZに依存せず、JST暦日としてYYYY-MMを扱う。適用開始/終了は計画・サービス・時間枠の全条件の積集合。祝日等は補完しない。
- 跨日の予定は開始日が属する月へ所属し、終了日を明示して翌月/翌年も保持。週単位以外の予定は勝手な日付にせず未展開リストで返す。サービス/時間枠IDの重複、時刻や期間の不正は失敗。
- 予定と実績は別構造。actual=nullは未入力、not_providedは明示的な未実施、providedは実績日時。取消・削除でも実績を消さない。再生成の差分は追加/元計画から消えた予定を提示するが、現在の変更/実績を自動置換・削除しない。
- 前月コピーは同じ日番号を提案し、存在しない日をスキップ理由として返す。曜日での再展開とは区別する。実績はコピーせず、コピーIDで同一元行の再送を重複させず、既存対象月の行を上書きしない。対象月/元月の違いは拒否。
- この基盤PRだけではDB/API/UI/PDFを提供しない。後続PRで事業所スコープ付きの確定snapshot読取・月次保存版・明示的な差分確認へ接続する。第6表が利用可能とは表示しない。
