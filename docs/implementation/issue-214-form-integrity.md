# 取り込んだ書式の位置と対応（#214）

## 修正

- 責任者の書式の見直し・修正画面で、文字・丸・チェック・図の各欄の位置と幅・高さを mm 単位で変更できる。用紙寸法を使って表示し、用紙外・空欄・幅高さ0は保存操作の前に知らせる。
- 座標保存は既存の下書き更新APIを使用する。AIを再実行せず、対応・値・元PDFを変更しない。権限、事業所境界、contentShaによる競合検出、公開済み版の変更禁止を維持する。
- 丸の選択肢はPDF内の実際の文字位置から語全体を囲む。文字を取れない場合や近くに同程度の候補がある場合は決め打ちしない。Tel/Fax/電話の印字に重なる文字欄は、印字の後ろから入力する。
- M/T/Sなどの元号群は、近傍の日付との対応が一意なら同じ日付の元号にする。日付が不明なら共通の単一選択にする。独立したboolにはしない。
- 図の参照（入れ子を含む）を図の欄へ揃える。既存の図データを文字として読む不正な対応は公開前に拒否する。

## 既存の書類との関係

公開済みの書式と作成済みの書類は書き換えない。既存の位置の修正は「書式を直す」で下書きを作って行う。取り込み時のTel・元号・図の自動補正は、修正後に取り込む書式に適用される。古い下書きで意味の対応自体が壊れている場合は、再取り込みして確認する。既存の利用者の値は移し替えない。

文字を含まないスキャンPDFや推測が必要な配置を、完全自動で正しい位置に直す保証はない。手動での位置修正と試し印字を使う。
